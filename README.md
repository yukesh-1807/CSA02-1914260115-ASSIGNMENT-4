## Task Descriptions and Results

### Task 1 – Data Design Review

Designed a patient register using structures and nested structures. Implemented structure pointers to store and display patient details, including name, age, phone number, blood pressure and visit date.

### Task 2 – Courier Parcel Tracking

Designed nested structures for parcel details, sender and receiver information. Implemented structure-pointer operations and selection sorting based on parcel weight.

### Task 3 – Unions and Memory Layout

Implemented a tagged union for weather-station sensor packets. Demonstrated temperature, humidity and status values, along with structure size and memory layout analysis.

### Task 4 – Structure Forensics

Identified and corrected structure-passing and pointer-access errors. Used structure pointers and the arrow operator to update bank account balances with interest.

### Task 5 – Storage Classes

Implemented and compared automatic, static, extern and register storage classes. Demonstrated variable scope, lifetime, initialization and counter behaviour.

### Task 6 – College Canteen Inventory and Billing

Designed a canteen inventory and billing system using structures, nested structures and tagged unions. Implemented sales recording, stock validation, expiry warnings and revenue-based sorting.
